# net/ether

Ethernet basics: the MAC address type, and the Port protocol, a thing frames are sent through and received from.

```vertex
import "net/ether"
```

## Types

- **`Mac`** (struct)
- **`Port`** (protocol)
- **`LoopbackPort`** (class)

Part of the [`net`](https://github.com/vertex-language/net) repository.
